# 老板的写作风格标准 · v0.1

> 后续所有内容（帖子、博客、文档、视频脚本）按这个风格写。

## 3 个核心

### 1. 直接、具体、不装
- 不说"副业"，说"side project"
- 不说"贵"，说"charge $3-20 per million tokens"
- 不说"难"，说"no way to open a Stripe account"
- 不说"打造卓越产品" → 说"我做了什么"

### 2. 痛点前置 + 数字支撑
- "Two months ago, I was laid off" → 时间
- "$0 initial budget" → 数字
- "Big AI platforms charge $3-20 per million tokens, yet the underlying inference cost is only a tiny fraction of that" → 对比
- 不用"行业领先"这种空话

### 3. 承认不知道 + 求真实反馈
- "I am NOT selling this yet"
- "Current placeholder name: CheapToken — any better naming suggestions?"
- "What core features would make you switch from mainstream AI APIs to this service?"
- 不用"欢迎提出宝贵意见"

## 禁用词

```
打造 / 赋能 / 卓越 / 领先 / 一站式
痛点 / 场景 / 闭环
共同 / 探讨 / 携手
重磅 / 全新 / 升级
亲 / 各位 / 大家好（除开头一次性）
```

## 推荐词

```
实打实 / 真实 / 直接
数字 / 时间 / 对比
学到 / 踩坑 / 试过
跑通 / 跑不起来
```

## 段落规则

- 段落短（3-5 句）
- 句子短（少用"并且"、"然而"连接）
- 用第一人称（"I" 不是 "we"）
- 不带感叹号
- 不加 emoji（除非发 Twitter）
- 不引用名人名言

## 段落模板

```
第一段：我是谁 + 我做了什么（一句话）
第二段：痛点（用数字 / 场景）
第三段：方案（不吹不黑）
第四段：现状（实事求是）
第五段：求反馈（具体问题）
```
